# docs/research/assets/

## 职责

- 存放调研过程中对公开页面、应用商店页面、项目界面截取的图片。
- 文件名使用「对象-页面-日期」格式，便于回溯取证时间。

## 不负责

- 报告正文（在 `docs/research/`）。
- 生成物（渲染出的 PDF 不放这里，见仓库根目录产物约定）。

## 对外接口

- 由 `docs/research/我的账本工具-横纵分析报告.md` 以相对路径引用。

## 依赖

- 无。

## 已知限制

- 截图可能包含第三方商标与品牌元素，仅用于分析与引用。
- 不使用未获授权的内容；不截取需要登录后的私有页面。
