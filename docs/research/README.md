# docs/research/

## 职责

- 存放竞品调研报告、对比矩阵、架构图与截图。
- 报告的结论决定「fork / 借鉴 / 自研」与类目体系选型。

## 不负责

- 产品需求的最终定义（结论回填到 `docs/specs/产品规格-我的账本.md`）。
- 实现细节（在 `docs/architecture/架构.md` 与各模块 README）。

## 对外接口

| 文件 | 内容 |
|---|---|
| `我的账本-横纵分析报告.md` | 横纵分析法报告：需求前史、竞品对比、架构图、结论 |
| `assets/` | 公开页面截图 |

## 依赖

- 调研只使用公开页面与开源仓库，不注册、不登录任何商业产品。

## 已知限制

- 商业 App 的内部实现不可见，架构只能从公开资料与行为推断；推断必须在报告中标注。
- 截图可能含第三方商标，仅作分析引用，不用于分发。
