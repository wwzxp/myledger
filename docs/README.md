# docs/

## 职责

- 作为文档地图：每类文档一个子目录，每个子目录有自己的 `README.md`，本文件只做索引，不复制内容。
- `docs/**/*.md` 的文件名使用中文；目录名使用英文。

## 不负责

- 代码注释（跟着代码走）。
- 变更履历（在根 `CHANGELOG.md`）。
- 文件级索引（在根 `INDEX.md`）。

## 对外接口

| 目录 | 内容 |
|---|---|
| `specs/` | 产品规格（PRD） |
| `architecture/` | 分层、数据流、模块边界（mermaid） |
| `adr/` | 架构决策记录，一个决策一个文件 |
| `research/` | 竞品调研报告与截图 |
| `reference/` | 外部技术参考（与本项目业务无关的通用做法） |

## 依赖

- 无代码依赖。`npm run doc:check` 检查本目录下所有 md 的本地链接与 README 完整性。

## 已知限制

- 一事实一出处：同一事实只在最靠近实现的那份文档定义，其他文档链接引用。
