# docs/adr/

## 职责

- 记录**架构级**决策：为什么这样选、当时有哪些选项、选它的后果。
- 文件名格式：`YYYY-MM-DD-主题.md`，主题用中文短语。

## 不负责

- 用户可见的功能变更（在 `CHANGELOG.md`）。
- 使用说明与产品需求（在 `docs/产品规格-我的账本工具.md`）。
- 临时讨论与未定事项（写在对应文档的“尚未确定”一节）。

## 对外接口

| 文件 | 决策 |
|---|---|
| `2026-11-05-技术栈与运行边界.md` | 技术栈、部署边界、AI 调用方式、数据落盘 |

## 依赖

- 决策若影响模块边界，需同步 `docs/架构.md`。

## 已知限制

- ADR 一经写入不修改正文；结论变化时新增一份并标注取代关系。
