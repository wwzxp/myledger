# 安装与运行

## 安装（装在 E 盘，不写 C 盘）

```bat
python -m venv E:\ai\apps\myledger\.venv
E:\ai\apps\myledger\.venv\Scripts\python.exe -m pip install E:\ai\code\myledger
```

安装后 `myledger.exe` 位于 `E:\ai\apps\myledger\.venv\Scripts\`，可在**任意目录**运行。

## 配置

配置只有一种来源：**TOML 文件**。应用不读取环境变量。

查找顺序：

1. `--config <路径>` 显式指定
2. 当前目录的 `myledger.toml`
3. 用户配置 `~/.config/myledger/myledger.toml`（Windows 下为 `C:\Users\<你>\.config\myledger\myledger.toml`）
4. 都没有时用内置默认值

`--config` 一旦给出就成为本次进程的固定配置：后续子命令与 HTTP 处理都用它，
不再退回目录发现。所以配置文件可以叫任意名字——`scripts/start-windows.cmd`
用的是 `ai-ledger.toml`，此时第 2、3 步都不会命中，缺了这条固化就会读到内置默认值。

示例（`E:\ai\apps\myledger\myledger.toml`）：

```toml
[database]
path = "E:/ai/apps/myledger/data/ledger.db"

[model]
endpoint = "http://127.0.0.1:8080/v1/chat/completions"
name = "minicpm-v-4.7-1b"
timeout_seconds = 30
min_confidence = 0.55

[import.account_map]
# "某银行信用卡(0000)" = "某银行信用卡"
```

字段说明：

| 字段 | 作用 | 默认 |
|---|---|---|
| `database.path` | SQLite 文件位置，目录会自动创建 | 用户目录下的 `bookkeeping.db` |
| `model.endpoint` | 本地 llama-server 的 OpenAI 兼容接口 | `http://127.0.0.1:8080/v1/chat/completions` |
| `model.name` | 模型名（传给 `/v1/chat/completions`） | `minicpm-v-4.7-1b` |
| `model.timeout_seconds` | 单次请求超时 | `30` |
| `model.min_confidence` | 低于该值的分类结果丢弃 | `0.55` |
| `import.account_map` | 支付宝付款方式名 → 本地账户名 | 空（保留原名） |

## 运行

```bat
cd E:\ai\apps\myledger
E:\ai\apps\myledger\.venv\Scripts\myledger.exe
```

或显式指定配置文件：

```bat
myledger.exe --config E:\ai\apps\myledger\myledger.toml
```

浏览器打开 `http://127.0.0.1:8765` → 侧栏「导入」→ 拖入账单。

## 子命令

```bat
myledger.exe init                     :: 初始化数据库
myledger.exe classify-pending         :: 本地模型给待确认条目补类目
myledger.exe --version
myledger.exe --help
```

## 已知限制

- 只监听回环地址，无鉴权；任何本机进程都可访问。
- 单进程，无持久队列；重启会中断进行中的导入（已入库部分不回滚）。
- 配置文件解析失败会直接报错，不做静默回退——配置错误应当响。
