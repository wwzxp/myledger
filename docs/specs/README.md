# docs/specs/

## 职责

- 存放产品规格文档，文件名使用中文，如 `产品规格-我的账本.md`。
- 规格由会话共识综合而成，不做二次访谈；未定事项在文末「尚未确定」列出。

## 不负责

- 架构分层与数据流（在 `docs/architecture/`）。
- 单个技术决策的理由（在 `docs/adr/`）。
- 竞品对比与选型依据（在 `docs/research/`）。

## 对外接口

| 文件 | 内容 |
|---|---|
| `产品规格-我的账本.md` | 问题陈述、用户故事、实现决策、测试决策、范围外、补充说明 |

## 依赖

- 调研结论回填（类目体系、是否复用开源项目）。
- 规格变更需同步根 `CHANGELOG.md`。

## 已知限制

- 规格描述的是目标行为；未实现的部分不得在 README 或对外文档中当作已实现来写。
