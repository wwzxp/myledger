# docs/reference/

## 职责

- 存放**与记账业务无关**的技术参考：UI 交互做法、工程套路、协议说明。
- 这些材料来自别的项目或通用实践，读它是为了解决「怎么做」，不是「做什么」。

## 不负责

- 竞品分析（在 `docs/research/`）。
- 本项目的产品规格（在 `docs/specs/`）。
- 本项目的架构决策（在 `docs/adr/`）。参考材料**不构成决策**；
  真要采用某个做法时，另行写 ADR 说明为什么选它。

## 对外接口

| 文件 | 内容 |
|---|---|
| `动态功能演示实现指南.md` | **别人产品**的逆向分析：左侧功能清单、右侧 640×400 自动播放、场景脚本与时间线。源项目为 Vue 技术栈，与本仓库无关，仅作思路参考。 |
| `assets/verify.js` | 演示动画的断言式验收脚本。读屏清单 JSON，把「界面细节偷懒」变成机器判定的失败（退出码 1）。 |
| `演示动画制作说明.md` | **从录屏做出演示动画的说明书**：含可直接复制的 `stage.js` / `kit.js` / `demo.css` 骨架、抽帧流程、光标十二坑、隐私脱敏、验收清单。面向零记忆的新项目，照抄即可跑。 |

## 依赖

- 无。参考材料不引入任何代码依赖。

## 已知限制

- 材料描述的是**别人项目的实现**，其中的目录结构、框架 API（如 Vue 组件、GSAP 插件）在本仓库并不存在。
  照搬前要先确认本项目的技术栈——这里是原生 HTML/CSS/JS，无构建步骤。
- 参考材料可能随源项目演进而过时，本仓库不做同步维护。
- 引用第三方代码或截图时注意其许可。
